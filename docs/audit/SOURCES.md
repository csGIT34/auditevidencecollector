## Conflicts and applicability cautions resolved during review

- Older Functions baseline language does not replace current hosting/network documentation. Treat site/SCM/auth and plan capabilities separately.
- Older Event Grid baseline feature exclusions for namespaces cannot override current Entra/MQTT guidance. Enumerate exact family before assigning a capability.
- Older Container Apps identity restrictions require current service verification; job execution permissions can exercise secrets/identities even without listSecrets.
- Modern Managed Redis guidance governs modern SKUs. Legacy Azure Cache for Redis baseline is not substituted.
- Grafana encryption and Prometheus workspace encryption are documented, but neither has a current executable encryption handler. Discovery of a guarantee is not implementation.
- Prometheus query private access, DCE/AMPLS ingestion and resource/workspace query modes are separate. Do not inherit Log Analytics identity or retention controls.
- Automation secure assets/runbooks have documented protection, but job/output content and unencrypted variables require their own scope. Native full-account backup is not assumed.
- Provider-managed encryption remains accepted even when a Microsoft recommendation suggests optional CMK. Organizational tailoring decides extra requirements.
- Feature recommendations are not proof of deployment state, universal NIST mandates, authorized costs or completed operating processes.
